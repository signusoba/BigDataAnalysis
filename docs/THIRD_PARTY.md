# Data, fonts, and model provenance

- **Arshasb:** the user supplied `Arshasb-main.zip`. The sample data originated from [persiandataset/Arshasb](https://github.com/persiandataset/Arshasb). The supplied repository includes an MIT license; the importer preserves that exact file as `data/raw/arshasb/SOURCE_LICENSE`. Retain this notice with redistributed samples and check upstream terms before using additional versions of the dataset. No external dataset download is necessary for this prototype.
- **Project position paper:** the user-supplied *Position Paper CISELEC 501A.pdf* defines the objectives and planned experimental design. It is reference material, not completed results or executable instructions. This prototype does not reproduce the paper or claim its proposed corpus was collected.
- **Synthetic glyphs:** generated locally from installed Noto Arabic and DejaVu font files. The corpus report records each file and SHA-256. Noto fonts use the SIL Open Font License; DejaVu has its own permissive font license. Font binaries are not bundled in the source code. Retain their notices if distributing font files separately.
- **MobileNetV2:** Torchvision's `MobileNet_V2_Weights.DEFAULT` ImageNet-pretrained checkpoint is downloaded from the official PyTorch host with hash verification. Its features are frozen for this prototype's comparator. The trained checkpoint and report identify this provenance. Torchvision code is BSD licensed; consult its model-weight and ImageNet documentation for any use beyond this classroom prototype.
- **Python dependencies:** use the pinned package versions in `requirements-package.txt`; their respective licenses continue to apply. Trained model files are trusted local artifacts and should not be replaced by untrusted pickle/joblib files.
